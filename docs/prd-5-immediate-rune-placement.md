# Immediate Rune Placement

Supersedes charging rules in PRDs 0, 2, 3, and 4.

## Rules

- Any rarity fills a compatible empty slot in one placement.
- Placement removes the physical rune from hand, adds it to discard, creates the wall copy, then resolves cast effects.
- Slot row and rarity do not change placement cost.
- No staged runes, charge fuel, progress counters, exact-type locks, virtual charge, or adjacent-charge effect.
- Filled slots remain unavailable.
- Dual-type slot-family matching remains unchanged.

## State

- Wall cells own completed rune identity and effect refs.
- Charge-based saved runs are invalidated.
